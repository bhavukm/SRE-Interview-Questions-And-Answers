As a Senior Site Reliability Engineer, my day-to-day responsibilities revolve around ensuring high availability, reliability, scalability, observability, security, and cost 

optimization of production platforms running on AWS EKS. I primarily support Java Spring Boot and Spring MVC based microservices deployed through GitLab CI/CD pipelines and 

ArgoCD using a GitOps model. My work includes troubleshooting production deployment failures, debugging CI/CD pipeline issues across stages like platform validation, Docker 

image builds, Snyk security scans, Helm deployments, and EKS rollout failures. I regularly work with Terraform-based Infrastructure as Code automation for provisioning and 

managing AWS resources. On the observability side, I design and manage Grafana dashboards, Prometheus Mimir metrics collection, Grafana Loki log aggregation, and Grafana 

Tempo distributed tracing to improve system visibility and incident troubleshooting. I also define and monitor SLI, SLO, and SLA metrics for critical services, configure 

proactive Grafana alerting, and participate in incident response for production outages and performance degradation. In addition, I have worked on multiple enterprise-level 

tool migrations including Datadog to Grafana, Sumo Logic to Grafana Loki, Spinnaker to ArgoCD, and Jenkins test jobs to GitLab CI. I’m also involved in AWS cost optimization 

initiatives using tools like CloudZero to optimize EKS workloads and cloud spending. Currently, I’m working on an AI-driven SRE initiative where we are leveraging AI models 

and observability data to automatically recommend optimized Kubernetes Resource Requests and Limits for Java Spring Boot applications running on AWS EKS, helping improve 

application performance, cluster efficiency, and infrastructure cost optimization simultaneously.
